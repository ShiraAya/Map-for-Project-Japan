# PJM 1.3.11 — 配套 PJR 0.1.24

JAR：4,969,194 字节。关闭游戏后替换旧 PJM，仅保留一个版本；配合 PJR 0.1.24-alpha。

只更新版本元数据及离线地图，40 个生产 Java 文件、93 个 class 与 PJM 1.3.10 逐字节相同，加载器、界面、渲染算法及运行时缓存上限均未变。

地图同步港区细长条清理与高程缺失边缘修复，指纹为 01541c9dd225f303f195。1,345 个条目全部使用实际 PJR 0.1.24 核心与数据渲染，没有全局接受旧指纹的例外。全包逐项读取不触发地形/水系查询，错误指纹会拒绝旧图。默认概览 24 张可见瓦片的后端读取及 PNG 解码约 69.556 ms。

图一东京湾长条在 10、11 级地图中检查 3,712 个像素，全部显示海面。389 河、221 湖与 PJR 的适配检查通过。具体断言和采样数量见 validation/compatibility-1.3.11.txt。

离线构建时复用从同一核心解码的海岸节点以减少重复解压；4,184 个瓦片逐项核对，绑定源数据/解码器指纹，东京和大阪两张概览 PNG 与普通解码路径逐字节相同。此工具缓存不打进 JAR，也不改游戏运行时内存配置。

全国概览及既定沿海窗口可直接读取；窗口外、更高细节仍在本机离线生成。地图反映当前地理模型，PJR 旧存档区块不会自动重塑。未运行图形 Minecraft、GPU、道路层或 FPS 测试，以上计时不含引擎初始化。
